# New Brew

A static site for catching up on new and updated Homebrew packages — what you
see scroll by in the `brew update` preamble, presented as a scannable,
console-styled timeline. It tracks both formulae and casks over a 60-day
window, remembers what you've already seen, and links out to each project's
homepage and brew.sh page.

See [DESIGN.md](DESIGN.md) for the full architecture (hybrid data model,
browser gap-fill, caching strategy).

## Usage

Scan the timeline, expand a row to read what the package does, and click out
to the project site if interested.

## Development

```sh
npm install
npm run dev
```

Production build and local preview:

```sh
npm run build
npm run preview
```

## Data

`static/data/changes.json` is generated by a scheduled GitHub Action
(`.github/workflows/data.yml`, 3× per day during US work hours) and committed
to the repo. Those bot commits carry `[skip ci]` so they don't trigger
deployments; the browser gap-fills the delta against current tap HEAD, and the
next real push deploys everything.

## Deployment

The site deploys to GitHub Pages via `.github/workflows/deploy.yml` on every
push to `main`.
